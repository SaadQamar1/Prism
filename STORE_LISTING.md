# Title

Prism

# Short description

A private browser photo studio with layers, drawing, filters and local project saving. Edit and export images without an account.

# Full description

Prism gives creators, students and small businesses a private space to edit images, make thumbnails and prepare everyday designs.

Open an image or start with a blank canvas. Crop, resize, rotate, draw, add text, work with layers and adjust colors using the miniPaint editing engine. A charcoal workspace and warm orange controls keep your artwork at the center.

Organize projects with search, favorites, renaming and duplication. Your work saves automatically in your browser and remains available when you close and reopen it. Export PNG, JPEG or WebP images, or download an editable Prism backup to import later.

Prism is free and browser based. No account, Docker, API keys or paid services are required. It is an independent app powered by the open source miniPaint editor, with attribution and license notices included.

Projects stay in the browser and device where you created them. There is no cloud sync, collaboration, stock-image search or AI generation. Clearing browser storage or using private browsing can remove projects, so download backups of important work. Text uses system fonts. Large images may use substantial memory, and some effects require browser WebGL support.
